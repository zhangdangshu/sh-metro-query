# 上海地铁路径与票价查询

一个上海地铁路径与票价查询工具，直接调用上海地铁官网的查询接口，采用 Material Design 设计。作为一个轻量级、响应式的单页面 Web 应用，其开箱即用。

**==隐私方面，==**所有的站点选择及查询请求，均直接由用户的浏览器发送至上海地铁官方接口，我们无法查看你的任何信息，但是上海地铁可能会使用或存储你的信息。使用我们的服务即代表你已经知情且你愿意向 https://service.shmetro.com/cphc/index.htm 输入信息。

## 使用指南

1. **在起点站和终点站的搜索框内搜索站点。**你可以：

   - **模糊搜索站点名称。**例如输入“南京”后，可在列表中找到南京东路站和南京西路站。

   - **输入线路编号以查询线路上的所有站点。**例如输入“11”后，可在列表中找到 11 号线的所有站点，其中 41 代表浦江线，51 代表市域机场线。

   **==请注意，==你需要在弹出的下拉列表中选中站点才可以保存你的选项，**覆盖输入或不在下拉菜单中选择站点的输入被认为是无效的。

2. **点按完成按钮即可查看路线。**

3. **点按切换按钮可以调换起点和终点。**

4. **==请注意，==线路规划和票价预测时默认星期为“周日”，默认票种为“交通卡 / Metro 大都会 App“。**

## 功能

- **全覆盖站点数据。**直接内置完整的上海地铁站点数据（包含数字线路 1 至 18 号线、浦江线、市域机场线）。
- **智能模糊搜索。**支持站点中文名模糊匹配和线路筛选。详见“使用指南”。
- **响应式设计。**针对桌面端和移动端进行了深度适配，移动端自动切换为垂直布局和上下交换图标。
- **Material Design 3. **基于 `@material/web` 官方 Web Components，提供优秀交互体验。避免”AI 设计“。
- **零依赖构建**：纯原生 HTML/CSS/JS 实现，无需 Node.js 或任何打包工具。及其轻量化。

## 逻辑

- **站点数据**：`rawStations` 数组中存储了站点名称与线路编码。
- **搜索逻辑**：输入框监听 `input` 事件，通过防抖 (Debounce) 优化性能。若输入为纯数字，则严格匹配线路；若为文本，则匹配站名或线路名。
- **路径查询**：通过 `fetch` 请求上海地铁的路径规划接口，获取结果后，复用官方提供的 `planTrip` JS 类进行结果渲染。
